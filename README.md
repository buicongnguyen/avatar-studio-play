# Avatar Studio

Open **https://buicongnguyen.github.io/avatar-studio-play/**.

This repository contains the reviewed built website. Development is in the private avatar-studio repository on main. The previous `/test/` snapshot is preserved; current releases use the root page.

Start with updated Nabi, Nabi original, or Haru in their default clothes. Access accepts `nabi` as a shortcut to updated Nabi; `buicongnguyen` unlocks all ten character cards, wardrobe choices, PC HD where available and GLB import. These are convenience demo switches, not security; browser assets are publicly downloadable.

The new Korean gymnast Light has 39,496 triangles, complete barefoot geometry, 55 embedded motions, body sliders and face controls. Her PC HD tier has 142,728 triangles and a 23.75 MB download, with the same motions and controls. Select her card, then change Model detail to HD after unlocking. Her design remains a stylized interpretation of generated references.

In **Move → Combat**, load 15 motions: fighting stance, low/high punches and kicks, stationary/forward/backward jumping attacks, low/high blocks, and separate left/right open-hand slaps. **Start combat demo** queues the pack. The simplified finger rigs still produce somewhat loose fists. This is an animation preview, without damage or opponents.

In **Move → Acrobatics**, load a captured **Backflip** and **Forward flip · kick entry**. Full-body views fit the complete travel path. Flips play once, and replay starts at the authored origin. In **Move → Dance**, load original **YMCA-style gestures** and **Robot dance**, without music. These are not official Unitree performances. The three new packs total under 0.75 MB of animation data per avatar and add no model triangles or textures.

The existing extra-motion pack still provides **Normal walk**, **Normal run**, gym and everyday actions. The earlier crouched-looking clips remain as **Low walk / Low run**. Playlists, frame scrubbing and the repeating dance demonstration are included.

Korean gymnast Light/HD now default to approximately 5% thinner thighs, measured on the mesh. Supported female avatars have a wider upper bust-size range and clear inward/outward spacing controls; updated Nabi starts slightly fuller and more inward. Existing saved body presets can override these defaults.

**Settings → Face** adds closed-eye smiles (closed or slightly open mouth), a closed-eye kiss, open-eye surprise, Gentle cry and Shy with soft cheek colour. Full rigs offer 23 supported presets; Haru offers 18, and original Nabi has no expression rig. Surprise uses neutral-open lids and raised brows because these rigs have no eye-widening morph; Gentle cry does not add tears. Cheek colour is a studio shader effect restored by studio presets, not baked into ordinary exported GLB materials.

Play offers the two-thumb touch pad by default and an optional **Grab & move** hand. Press/Pull share Force, with the contact area kept clear during dragging. Compatible faces react Friendly → Happy → Friendly → Neutral; optional upper-body reaction is bounded and off initially. This is visual deformation, not full soft-body or balance simulation.

The interface has Violet, Plum & gold and Lagoon palettes with light/dark mode. Camera changes respect reduced motion. Shots saves pictures, silent 5/10/30-second videos where the browser supports recording, and GLB exports. Recordings stay local; no microphone is used. Actual phone performance and browser recording support vary.
