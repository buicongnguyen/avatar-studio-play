# Avatar Studio

Open **https://buicongnguyen.github.io/avatar-studio-play/**.

This repository contains the reviewed built website. Source development is maintained separately on the private avatar-studio repository's main branch.

The studio includes nine avatar choices after unlocking Settings, including the unchanged **Nabi · original** with three outfits, the upgraded Nabi, and two ponytail candidates with Light/PC HD tiers. It supports common actions and dancing, body and supported face controls, presets and GLB import/export. Generated reference thumbnails identify each avatar.

In Touch mode, use the bottom-left pad to position the contact and hold the bottom-right Press button to indent the skin. Direct interaction with the avatar is also available. These are bounded visual dents.

The earlier `/test/` page is retained as a snapshot. Current releases are at the root URL above. Imported GLBs stay in your browser session.
