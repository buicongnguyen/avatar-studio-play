# Avatar Studio demo

Open https://buicongnguyen.github.io/avatar-studio-play/

This repository contains the built browser demo. It includes body and outfit controls, motion previews, local GLB import/export, and generated girl/boy reference PNGs. Nabi and Haru are the current 3D starter assets; the sample images are appearance targets for upcoming models.

Use Sample images in the library to view or download the 1024x1024 PNGs. Imported GLBs stay in your browser session.
